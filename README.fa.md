## 🧐 اودی‌فلو (Audiflow) چیست؟

**Audiflow** یک نرم‌افزار سبک، رایگان و متن‌باز برای **تبدیل، ویرایش و پخش فایل‌های صوتی به شکل کاملاً آفلاین** در سیستم‌عامل‌های ویندوز، مک، لینوکس و اندروید است.

این برنامه ترکیبی جامع از یک **مبدل فرمت‌های MP3، FLAC، WAV، ابزار برش صدا، حذف سکوت، تقسیم‌کننده فایل، تقویت‌کننده حجم صدا و یک موزیک پلیر محلی** در یک پکیج واحد است.

تمامی عملیات پردازش صدا به شکل محلی بر روی دستگاه شما و به کمک نسخه باندل‌شده **FFmpeg** انجام می‌گیرد؛ بنابراین نیازی به آپلود فایل‌های شخصی به سرویس‌های آنلاین تبدیل فرمت ندارید.

برنامه با هسته قدرتمند **Tauri 2 + Rust** در بک‌اند و واسط کاربری مدرن **React 19 + TypeScript + Tailwind CSS + Zustand** پیاده‌سازی شده است.

### چرا Audiflow؟

- 🔒 **حریم خصوصی و پردازش ۱۰۰٪ آفلاین** — فایل‌های صوتی شما هرگز از دستگاهتان خارج نمی‌شوند.
- ⚡ **سرعت پردازش بالا** — بهره‌گیری از حداکثر توان پردازشی Rust و موتور FFmpeg.
- 🎵 **جعبه ابزار جامع صوتی** — تبدیل، برش، تقسیم، حذف سکوت، افزایش صدا و پخش آهنگ‌ها در یک نرم‌افزار یکپارچه.
- 🌍 **پشتیبانی از چندین سیستم‌عامل** — ویندوز، مک، لینوکس و اندروید.
- 🆓 **رایگان و متن‌باز** — توسعه‌یافته بر پایه فناوری‌های مدرن و استانداردهای باز.

## ✨ امکانات و قابلیت‌ها

### 🔄 مبدل صوتی (Audio Converter)

تبدیل فرمت‌های مختلف صوتی با پایپ‌لاین بهینه FFmpeg به صورت محلی.

- تبدیل دسته‌ای فایل‌های صوتی (Batch Conversion)
- تبدیل فرمت MP3
- تبدیل فرمت FLAC
- تبدیل فرمت WAV
- تبدیل فرمت AAC
- تبدیل فرمت M4A
- تبدیل فرمت OGG
- تبدیل فرمت OPUS
- تنظیمات سفارشی بیت‌ریت (Bitrate) و کیفیت
- انتخاب نرخ نمونه‌برداری (Sample Rate) و تعداد کانال‌ها
- سیستم مدیریت صف پردازش (Queue)
- نمایش زنده درصد پیشرفت و وضعیت هر فایل
- امکان لغو تبدیل هر فایل به صورت جداگانه
- بررسی و اعتبارسنجی خودکار استریم‌های رسانه

اودی‌فلو در صورت امکان تمامی عملیات را در یک گراف پردازشی واحد FFmpeg انجام می‌دهد تا از انکودهای مکرر و افت کیفیت جلوگیری شود.

## ✂️ برشگر با موج صدا (Waveform Audio Trimmer)

ویرایش بصری و برش قطعات صوتی با استفاده از نمایشگر موج صدا.

- پیش‌نمایش تعاملی شکل موج صوت
- تعیین دقیق زمان شروع و پایان
- برش با دقت میلی‌ثانیه
- پیش‌شنیدن بازه انتخابی قبل از ذخیره خروجی
- پردازش بسیار سریع و محلی
- بسیار کاربردی برای آهنگ‌ها، پادکست‌ها، صداهای ضبط‌شده، مصاحبه‌ها و برش زنگ موبایل

---

### 🤫 حذف‌کننده سکوت‌ها (Silence Remover)

تشخیص و حذف خودکار بخش‌های بی‌صدا و خالی از فایل‌های صوتی.

- تشخیص هوشمند بخش‌های ساکت
- امکان تنظیم آستانه دسی‌بل (Threshold)
- تعیین حداقل مدت زمان سکوت
- پردازش بدون تخریب و حفظ پیوستگی صوت
- کاربردی برای پادکست‌ها، تدریس‌ها، مصاحبه‌ها و کتاب‌های صوتی

---

### ✂️ تقسیم‌کننده فایل صوتی (Audio Splitter)

تقسیم فایل‌های صوتی طولانی به بخش‌های کوچک‌تر.

- تقسیم بر اساس مدت زمان مشخص (مثلاً هر ۶۰ دقیقه)
- تقسیم بر اساس تعداد قطعات دلخواه
- حفظ باقی‌مانده فایل در قطعه آخر به شکل خودکار
- سازگاری کامل با فرآیند حذف سکوت
- پردازش در صف تبدیل

---

### 🔊 تقویت‌کننده صدا (Sound Booster)

افزایش بلندی صدای فایل‌ها به همراه مهار هوشمند اعوجاج و دیستورشن.

- افزایش حجم صدا و شفاف‌سازی
- پریست‌های آماده برای انواع محتوا
- لیمیتور سخت‌افزاری داخلی (`alimiter`) جهت جلوگیری از آسیب به بلندگو
- کنترل بهینه بر روی ولوم نهایی خروجی
- مناسب برای ضبط‌های کم‌حجم، ویس‌های ضعیف، موسیقی و پادکست

---

### 🎵 پخش‌کننده و کتابخانه موسیقی (Music Player & Local Library)

استفاده از Audiflow به عنوان یک موزیک پلیر سبک، سریع و آفلاین.

- اسکن سریع فایل‌های صوتی روی حافظه دستگاه
- سازمان‌دهی بر اساس آهنگ‌ها، آلبوم‌ها و خوانندگان
- کتابخانه محلی و ذخیره آهنگ‌های برگزیده (Favorites)
- یکپارچگی کامل با MediaStore اندروید
- کنترل پخش از روی لاک‌اسکرین و اعلانات سیستم
- پشتیبانی از دکمه‌های کنترل مدیا روی هدست و کیبورد
- ذخیره مستقیم خروجی‌ها در مسیر استاندارد `Music/Audiflow` در اندروید

## 🎧 فرمت‌های صوتی پشتیبانی‌شده

Audiflow از انواع فرمت‌های صوتی رایج پشتیبانی می‌کند:

| فرمت | توضیحات |
| :--- | :--- |
| **MP3** | فایل صوتی فشرده محبوب |
| **FLAC** | فایل صوتی بدون افت کیفیت (Lossless) |
| **WAV** | داده‌های صوتی خام (PCM) |
| **AAC** | کدگذاری صوتی پیشرفته |
| **M4A** | فرمت صوتی کانتینر MPEG-4 |
| **OGG** | فرمت آزاد Ogg Vorbis |
| **OPUS** | کدک صوتی مدرن و بهینه |

گزینه‌های انکودینگ ممکن است بسته به انکودرهای FFmpeg و فرمت خروجی انتخاب‌شده متفاوت باشند.

## 🛠️ کامپایل و بیلد از سورس

برنامه Audiflow متن‌باز است و می‌توانید آن را به صورت لوکال کامپایل کنید.

### پیش‌نیازها

- [Node.js](https://nodejs.org/) نسخه ۲۰ یا بالاتر
- [Rust](https://www.rust-lang.org/tools/install) نسخه Stable
- [pnpm](https://pnpm.io/) نسخه ۹ یا بالاتر
- وابستگی‌های سیستمی پلتفرم طبق [راهنمای رسمی پیش‌نیازهای Tauri](https://tauri.app/start/prerequisites/)
- ابزارهای بیلد FFmpeg در صورت نیاز به کامپایل اختصاصی

### کلون کردن ریپازیتوری

```bash
git clone https://github.com/javadSharifi/Audiflow.git
cd Audiflow
```

### نصب وابستگی‌ها

```bash
pnpm install
```

### آماده‌سازی FFmpeg

```bash
pnpm fetch:ffmpeg
```

### اجرای محیط توسعه

```bash
pnpm tauri dev
```

### ساخت پکیج نهایی (Production Build)

```bash
pnpm tauri build
```

فایل‌های نهایی بیلد در مسیر زیر تولید خواهند شد:

```text
src-tauri/target/release/bundle/
```

## ❓ سوالات متداول (FAQ)

### اودی‌فلو (Audiflow) چیست؟

اودی‌فلو یک نرم‌افزار رایگان و متن‌باز برای **تبدیل فرمت‌های صوتی، ویرایش، برش، حذف سکوت و پخش موسیقی به صورت آفلاین** در ویندوز، مک، لینوکس و اندروید است.

### آیا این مبدل صوتی واقعاً آفلاین کار می‌کند؟

بله. Audiflow تمامی فرآیندهای صوتی را با استفاده از FFmpeg داخلی دستگاه شما انجام می‌دهد و هیچ فایلی به وب‌سرویس‌ها ارسال نمی‌شود.

### چه فرمت‌هایی قابل تبدیل هستند؟

شما می‌توانید فایل‌های خود را به فرمت‌های **MP3، FLAC، WAV، AAC، M4A، OGG و OPUS** و برعکس تبدیل نمایید.

### آیا می‌توانم فایل FLAC را به MP3 تبدیل کنم؟

بله، به سادگی می‌توانید فایل‌های فشرده بدون افت کیفیت مانند FLAC را به MP3 تبدیل کنید.

### آیا امکان تبدیل WAV به MP3 وجود دارد؟

بله، فرمت‌های غیرفشرده WAV به راحتی به MP3 یا سایر فرمت‌های فشرده قابل تبدیل هستند.

### ابزار برش صدا چگونه کار می‌کند؟

Audiflow دارای یک برشگر بصری بر پایه موج صداست که به شما امکان می‌دهد نقطه شروع و پایان را با دقت میلی‌ثانیه مشخص کرده و قطعه مدنظر را ذخیره کنید.

### قابلیت حذف سکوت چیست؟

این ویژگی به صورت هوشمند سکوت‌های اضافه و وقفه‌های طولانی را از فایل‌های صوتی شناسایی کرده و آن‌ها را به شکل یکپارچه حذف می‌کند.

### آیا امکان تقسیم فایل‌های طولانی وجود دارد؟

بله. می‌توانید فایل‌های بلند را بر اساس زمان‌های مشخص (مثلاً هر ۴۵ دقیقه) یا تعداد پارت‌های دلخواه تقسیم کنید.

### تقویت‌کننده صدا (Sound Booster) چطور کار می‌کند؟

این ابزار ولوم و بلندی صدا را افزایش می‌دهد و مجهز به لیمیتور محافظتی است تا از ایجاد دیستورشن و خش‌دار شدن صدا جلوگیری کند.

### آیا Audiflow روی همه پلتفرم‌ها کار می‌کند؟

بله، این برنامه به صورت چندپلتفرمه برای **ویندوز، مک، لینوکس و اندروید** عرضه می‌شود.

### آیا استفاده از این برنامه رایگان است؟

بله، Audiflow کاملاً رایگان و متن‌باز (Open Source) است.
